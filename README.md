<h1>Interactive Markdown Previewer</h1>
<p>A lightweight, responsive web application that renders Markdown text into formatted HTML in real-time. Built using vanilla HTML, CSS, and JavaScript.</p>
<p><a href="https://domain-name" target="_blank" rel="noopener noreferrer">✨ View Live Demo</a></p>
<h2>🚀 Features</h2>
<ul>
<li><strong>Live Preview:</strong> Instantly view rendered HTML as you type.</li>
<li><strong>Copy HTML:</strong> One-click button to copy the generated HTML code directly to your clipboard.</li>
<li><strong>Split-Screen Layout:</strong> Dual-pane design for side-by-side editing and viewing.</li>
<li><strong>Responsive Design:</strong> Automatically adapts to mobile and smaller screen sizes.</li>
</ul>
<h2>🛠️ Built With</h2>
<ul>
<li><strong>HTML5:</strong> Semantic layout and structure.</li>
<li><strong>CSS3:</strong> Custom styles, variables, Flexbox layout, and media queries.</li>
<li><strong>JavaScript (ES6):</strong> DOM manipulation, event handling, and Clipboard API.</li>
<li><strong><a href="https://marked.js.org/">Marked.js</a>:</strong> Fast, lightweight Markdown parser.</li>
</ul>
